# 新品发布素材控制台

面向新品发布的一站式素材控制台：Web 时间线编辑器 + 三维预览 + 服务端确定性渲染 +
发布门禁（保密期 / 素材授权 / 公开字段 / 证据版本 / 安全区）+ 公开包导出与素材回收。

## 运行

```bash
npm start          # http://localhost:8080 （数据落盘 ./data）
npm test           # 验收场景（43 项断言，独立临时数据目录）
```

无外部服务依赖：关系库为 SQLite（better-sqlite3），对象存储为本地内容寻址（sha256）存储，
分片上传支持中断续传。页面右上角可切换账号体验 RBAC（admin/editor/legal/publisher/viewer）。

## 功能地图

| 页面 | 能力 |
| --- | --- |
| 产品型号 | 型号规格与公开字段白名单、产品保密期 |
| 卖点证据 | 卖点绑定具体型号 + 证据版本；参数订正生成证据新版本，旧卖点/旧产物自动失效 |
| 素材库 | 分片上传（可模拟中断并续传）、授权（internal/licensed/public）、素材级保密期、退役 |
| 场景与三维 | 场景清单锁定模型/材质/相机/灯光/纹理版本；WebGL 预览与服务端截图同清单重建并排对比；缺纹理显式告警 |
| 时间线 | 场景段/字幕/卖点标注三轨编辑；按渠道校验字幕安全区，冲突可点击定位 |
| 渲染任务 | 服务端确定性渲染多渠道预览成果；依赖诊断（缺失纹理/证据过期/型号错配）一键定位；占位产物禁止发布 |
| 发布 | 候选发布 → 法务审批 → 发布/定时发布；到点重检权限与全部门禁 |
| 导出与回收 | 公开包导出（仅公开字段、无内部评审备注、无未解禁模型）；GC 保留仍被候选发布引用的对象 |

## 关键设计

- **高低配隔离**：卖点通过 `selling_point_models` 绑定具体型号，渲染时校验
  `SP_MODEL_MISMATCH`，高配参数无法进入低配视频。
- **证据版本**：参数订正 = 证据新版本；卖点引用旧版即 `EVIDENCE_STALE`，渲染阻塞；
  已产出物在发布门禁复检时同样失效。
- **确定性渲染**：输入哈希 = sha256(场景清单对象哈希 + 时间线 + 渠道配置 + 卖点快照)；
  相同输入逐字节一致（见 `docs/render-paths.md` 与服务端/终端捕获对比）。
- **不静默占位**：缺纹理时浏览器端品红警示、服务端任务阻塞；显式占位产物仅内部预览且禁止发布。
- **导出净化**：公开包仅含已发布型号的公开字段规格、有效卖点、已发布渠道成果；
  不含内部评审备注、内部授权素材与未解禁对象。

## 验收场景（tests/acceptance.js）

S1 上传中断续传 · S2 纹理晚到（阻塞→诊断→重试，占位禁发） · S3 参数订正与高低配隔离 ·
S4 字幕安全区冲突 · S5 定时发布前权限变更 + 保密期 · S6 回收保留候选引用 ·
S7 公开包净化 · S8 渲染确定性与场景版本锁定。
